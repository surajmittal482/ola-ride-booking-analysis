# Ola Ride Booking Data Analysis

## Project Overview
This project analyzes Ola ride-booking data for July 2024 to explore booking trends, vehicle performance, revenue patterns, cancellations, and customer and driver ratings.

## Objectives
- Analyze total bookings and successful bookings.
- Examine daily ride volume and booking status.
- Compare booking value and ride distance across vehicle types.
- Analyze revenue by payment method.
- Investigate customer and driver cancellation reasons.
- Compare customer and driver ratings across vehicle categories.

## Tools and Technologies
- SQL — Data querying and analysis
- Microsoft Power BI — Dashboard visualization
- Microsoft Excel — Dataset management, if used

## Key Performance Indicators
- Total Bookings
- Successful Bookings
- Booking Success Rate
- Cancellation Rate
- Total Booking Value
- Average Ride Distance
- Customer and Driver Ratings

- `sql/` — SQL queries

## Dataset Information
The dashboard displays 103,024 bookings for July 2024. The data is tutorial-based/generated data and is not official Ola business data.
